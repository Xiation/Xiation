# Abyan Raditya Raka Pasha (Radit)

Final-year Electronics and Instrumentation student at Universitas Gadjah Mada, based in Yogyakarta.
I build systems that connect hardware to software, and I am moving toward backend engineering.

## Focus

- Hardware to software integration: sensor, camera and telemetry data into services and dashboards
- Concurrent processing for real-time data, such as live aerial image stitching
- Warehouse and logistics systems
- Computer vision for robotics perception: vision systems for a humanoid robot and an underwater vehicle, and my thesis (in progress)

## Selected work

**[BIMA Base Station](https://github.com/Xiation/BIMA-BASE-STATION)**
Ground control station for a UAV swarm. Team project. My part: the dashboard and the concurrent live stitching pipeline with sender-based image telemetry.

**[Vision Live Stitch](https://github.com/Xiation/VISION-LIVESTITCH)**
Live aerial image stitching between a drone sender and a ground station. Research and development, in progress.

**[Warehouse Management System](https://gitlab.com/bootcamp-stechoq/warehouse-system-cihuy)**
Warehouse system built during the Stechoq bootcamp.

**[coloGAMA](https://github.com/Xiation/coloGAMA-forked)**
Colorimetry hardware built to analyze the color of a solution, with an integrated application that can be opened from any device on the same local network.
